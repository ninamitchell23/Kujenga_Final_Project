# Karamoja Global Acute Malnutrition (GAM) Analysis

## Overview
This project analyzes trends in Global Acute Malnutrition (GAM) across nine aid-receiving districts in Karamoja, Uganda, between 2023 and 2025. The aim is to assess whether malnutrition levels have decreased over time using data extracted from official IPC (Integrated Food Security Phase Classification) reports.

## Data Source
The dataset was constructed from the following IPC reports:

* [IPC Uganda Karamoja Acute Malnutrition Report (February 2023 – January 2024)](https://www.ipcinfo.org/ipc-country-analysis/details-map/en/c/1156424/)
* [IPC Uganda Karamoja Acute Malnutrition Report (March 2024 – February 2025)](https://www.ipcinfo.org/ipc-country-analysis/details-map/en/c/1157054/)

## Study Area
The analysis covers nine districts in Karamoja:

Abim, Amudat, Kaabong, Karenga, Kotido, Moroto, Nabilatuk, Nakapiripirit, and Napak.

## Key Variable
Global Acute Malnutrition (GAM) refers to the **percentage (%) of children aged 6–59 months who are acutely malnourished**, including both moderate and severe cases.

## Objective
To determine whether GAM rates have decreased in the selected districts over the study period (2023–2025).

## Tools Used
- Python (Pandas, Matplotlib, NumPy)
- Kaggle Notebook environment
